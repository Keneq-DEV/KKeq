# KKeq

KKeq is a multilingual command-line media downloader for Windows. It uses yt-dlp to download videos or extract audio, supports playlists, lets you inspect media metadata or stream content with ffplay, and allows you to choose a download folder. The interface is available in Spanish, English, Russian, and Chinese.

Run `KKeq.bat` to start the application. On first launch, it checks for the required tools and asks before downloading missing dependencies into the local `lib` folder.
